Stripe Setup Guide

Follow these steps to connect real payments. This page is fully built — you just need to plug in your Stripe keys and create your products.

1

Create a Stripe account

Go to stripe.com and sign up. It's free. Once registered, go to your Dashboard → Developers → API Keys and copy your Publishable key and Secret key.

2

Create your 3 products in Stripe

In Stripe Dashboard → Products → Add product. Create these 3:

# Product 1

Name: STRIVE Pro Monthly

Price: $3.60 / month (recurring)


# Product 2

Name: STRIVE Pro Yearly

Price: $36.00 / year (recurring)


# Product 3

Name: STRIVE Lifetime

Price: $99.00 (one-time)

Copy the Price ID for each product (starts with price_).

3

Add your Stripe keys to this file

Replace the placeholder keys in the script below:

const PRICE_IDS = {

4

Set up a backend webhook (optional but recommended)

For production, create a simple server endpoint to handle checkout.session.completed webhooks so you can create user accounts automatically. Recommended: use Vercel serverless functions or Supabase Edge Functions — both are free to start.

// Vercel function: /api/stripe-webhook.js

import Stripe from 'stripe';

const stripe = new Stripe(process.env.STRIPE_SECRET);


export default async (req, res) => {

  const event = stripe.webhooks.constructEvent(

    req.body, req.headers['stripe-signature'],

    process.env.STRIPE_WEBHOOK_SECRET

  );

  if(event.type === 'checkout.session.completed'){

    // Create user account here

  }

  res.json({received: true});

}

5

Switch to Stripe Checkout (easiest production path)

For the fastest production deployment, replace the custom form with Stripe Checkout — Stripe's hosted payment page. It handles everything: card details, 3D Secure, Apple Pay, Google Pay, and receipts. One function call:

// Replace processPayment() with this:

async function stripeCheckout(plan) {

  const stripe = Stripe(STRIPE_KEY);

  await stripe.redirectToCheckout({

    lineItems: [{price: PRICE_IDS[plan], quantity: 1}],

    mode: plan==='lifetime'?'payment':'subscription',

    successUrl: 'https://strivehabit.com/welcome',

    cancelUrl: 'https://strivehabit.com/pricing',

  });

}
