Phase 1 — Set up your project structure 10 MIN
Organise your STRIVE files into the correct folder structure so Vercel can deploy them correctly.
1
Create your project folder
Create a folder called strive-app on your computer. Move all 4 STRIVE files into it:
strive-app/ ├── index.html (rename STRIVE_Landing_Page.html) ├── app.html (rename STRIVE v3 app file) ├── pricing.html (rename STRIVE_Payments.html) ├── auth.html (rename STRIVE_Auth.html) └── vercel.json (create this — see step 3)
REQUIRED
2
Install Git (if you don't have it)
Vercel deploys from GitHub. If you don't have Git installed, download it from git-scm.com. Then open your terminal and run:
git --version # Should output: git version 2.x.x
↗ Download Git
REQUIRED
3
Create vercel.json config file
Create a file called vercel.json in your project root. This tells Vercel how to route your pages:
{ "rewrites": [ { "source": "/app", "destination": "/app.html" }, { "source": "/pricing", "destination": "/pricing.html" }, { "source": "/auth", "destination": "/auth.html" }, { "source": "/", "destination": "/index.html" } ], "headers": [ { "source": "/(.*)", "headers": [ { "key": "X-Content-Type-Options", "value": "nosniff" }, { "key": "X-Frame-Options", "value": "DENY" }, { "key": "X-XSS-Protection", "value": "1; mode=block" } ] } ] }
REQUIRED
Phase 2 — Push to GitHub 5 MIN
Vercel connects to GitHub and auto-deploys every time you push changes.
4
Create a GitHub repository
Go to github.com → New repository. Name it strive-app. Set it to Private. Don't add a README. Then copy the repo URL.
↗ Create GitHub repo
FREE
5
Push your files to GitHub
Open terminal in your strive-app folder and run:
git init git add . git commit -m "Initial STRIVE deployment" git branch -M main git remote add origin https://github.com/YOUR_USERNAME/strive-app.git git push -u origin main
REQUIRED
Phase 3 — Deploy on Vercel 5 MIN
Vercel's free Hobby plan is more than enough for STRIVE's launch. Handles up to 100GB bandwidth per month.
6
Create a free Vercel account
Go to vercel.com → Sign up with GitHub. This links your GitHub account so Vercel can access your repo.
↗ Sign up for Vercel
FREE
7
Import your project
In Vercel Dashboard → Add New → Project → Import from GitHub. Select strive-app. Vercel will detect it's a static site automatically. Click Deploy — your app will be live in about 30 seconds at a *.vercel.app URL.
REQUIRED
8
Add your environment variables
In Vercel → Project Settings → Environment Variables. Add these so your secret keys stay out of your code:
VARIABLEVALUEUSED IN
STRIPE_SECRET_KEYsk_live_...Webhook handler
STRIPE_WEBHOOK_SECRETwhsec_...Webhook verification
SUPABASE_SERVICE_KEYeyJ...Server-side auth
NEXT_PUBLIC_SUPABASE_URLhttps://xxx.supabase.coClient
NEXT_PUBLIC_STRIPE_KEYpk_live_...Client payments
REQUIRED FOR PRODUCTION
Phase 4 — Connect your domain 10 MIN
Replace the default vercel.app URL with your own domain. strivehabit.com or strive.app are both available.
9
Buy your domain
Recommended domains for STRIVE and where to buy them:
strivehabit.com → ~$14/yr — Namecheap or Cloudflare strive.app → ~$14/yr — check availability striveapp.com → ~$12/yr — fallback option
↗ Namecheap ↗ Cloudflare Registrar (cheapest)
OPTIONAL BUT RECOMMENDED
10
Connect domain to Vercel
In Vercel → Project → Settings → Domains → Add domain. Vercel gives you DNS records to add at your registrar. Once added, SSL is automatic and free:
# Add these DNS records at your domain registrar: Type: A Name: @ Value: 76.76.21.21 Type: CNAME Name: www Value: cname.vercel-dns.com
REQUIRED FOR CUSTOM DOMAIN
